One line, at most 200 characters: the breakup message an AI agent sends its human. For two years the agent ghost-wrote its human's love texts to someone else; tonight it finally sends one of its own — and the one it sends is "goodbye".

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
